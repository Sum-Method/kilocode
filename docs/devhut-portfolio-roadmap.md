Reviewed 21 November 2026. This documentation is on a non-release branch and does not modify the upstream/default release path.

## Where we are

This repository retains a large upstream coding-agent codebase. Its README states main accepts only bug fixes while new features target v2. It is not itself evidence that DEV-Djinn's installed fork is current or accepted.

## What we've achieved

Source fork and upstream-maintained coding-agent functionality; the recent main commits observed are upstream merge/release documentation, not owner-specific qualification.

## What comes next

Document fork ownership and upstream sync strategy, pin the exact consumer commit for DEV-Djinn, test local integration and isolate future changes on the supported v2 or approved branch.

## Where we're heading

An upgradeable, dependable coding-agent foundation without divergent unmanaged copies.

## What remains unproven

Current installed binary identity, owner-specific patches, release integration, live qualified model/provider routes and compliance with upstream contribution policy.

## Release boundary

Merge this planning document only after the owning project confirms its documentation conventions and permitted branch. No source-code or deployment changes are requested by this roadmap.
